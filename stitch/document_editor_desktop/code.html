Mobile Checkout Redesign — Spec v2

calendar_today Oct 24, 2023 history 12 revisions

The objective of this redesign is to reduce friction during the mobile payment phase. Current metrics show a 14% drop-off at the "Shipping Methods" selection. This spec outlines the structural changes required for the 2.0 implementation.

Key Objectives

  • check_circle Consolidate Guest Checkout and Login into a single streamlined flow.
  • check_circle Implement Apple Pay / Google Pay as primary "Fast Track" options.
  • check_circle Reduce the number of form fields from 12 to 5 for shipping details.
warning

Warning

The legacy API for regional tax calculations will be deprecated by Dec 31st. All new checkout components MUST use the v4/tax-engine endpoint.
